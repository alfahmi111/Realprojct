# التشغيل والجودة (المرجع: SPEC §11.3، §11.4)

| البند | المطلوب | ما بُني | ما يبقى |
|---|---|---|---|
| البيئات (REQ-0500) | تطوير، اختبار، تشغيل فعلي منفصلة | التطوير: AMPPS + PostgreSQL محلي. الاختبار الآلي: مخطط `testing` منفصل لا يلمس بيانات التطوير. التشغيل: يُضبط من `.env` وحده | بيئة اختبار (staging) وتشغيل على الاستضافة داخل المملكة — بعد اختيار الاستضافة (Q11) |
| النسخ الاحتياطي (REQ-0501) | يومي مع استعادة لأي لحظة، واستعادة مختبرة دورياً | — | تتولاه PostgreSQL المُدارة لدى مزوّد السحابة (REQ-0481). يُفعَّل PITR عند اختيار المزوّد، وتُجدول تجربة استعادة دورية (Q11) |
| الاختبارات الآلية (REQ-0502) | مع كل تعديل، وإلزامية لكل حساب مالي | `composer ci` = الاختبارات + `composer audit` + `trace_check` | ربطها بخط CI عند وجود مستودع بعيد |
| المراقبة (REQ-0503) | تتبّع الأخطاء وتنبيه فوري عند التوقف أو البطء | مسار الصحة `/up`، وسجلات Laravel | اختيار أداة تتبّع الأخطاء والتنبيه (Q11) |
| التحديثات (REQ-0504) | تحديث دوري وفحص آلي للحزم ذات الثغرات | `composer audit` و`npm audit` ضمن `composer ci` | جدولة دورية على خادم CI |
| الأمان (REQ-0505…REQ-0508) | حمايات Laravel، تشفير، مصادقة ثنائية، فحص اختراق | حمايات Laravel مفعّلة، تشفير الجلسات وأسرار المصادقة الثنائية وبيانات التكاملات، مصادقة ثنائية إلزامية للمدير والمالك، فحص الإطلاق يمنع الإطلاق دون فحص اختراق | فحص الاختراق نفسه قبل الإطلاق؛ TLS على الاستضافة |

فحص الإطلاق: `php artisan platform:launch-check --production-config`.
